# ♨ 가상온천 모락

함께 담그는 메타버스 온천

## 👉 [지금 들어가기](https://dianexex-hub.github.io/morak/)

설치도, 가입도 필요 없어요. 링크를 열면 바로 시작돼요. PC와 휴대폰 모두 돼요.

## 이용 방법

1. 위의 **지금 들어가기** 링크를 열어요.
2. 남색 천(溫泉) 아래 주황색 **들어가기** 버튼을 눌러요. 소리를 켜두면 더 좋아요.
3. 1층 탈의실에서 시작해요. 사물함 앞에서 옷을 갈아입고, 정면 문으로 나가면 노천탕이에요.

| | PC | 휴대폰 |
|---|---|---|
| 걷기 | W A S D 또는 방향키 | 화면 왼쪽을 손가락으로 밀기 |
| 둘러보기 | 마우스를 누른 채 끌기 | 화면 오른쪽을 손가락으로 밀기 |
| 확대·축소 | 마우스 휠 | - |

- 탕 안으로 걸어 들어가면 자동으로 몸을 담가요.
- 화면 아래 버튼: **♨ 좋다~!** (외치기), **머리** (수건·양머리)
- 특정 장소에 가면 버튼이 더 생겨요: **갈아입기** (사물함), **매점** (음료), **눕기** (찜질방 매트)

## 둘러볼 곳

- **1층 탈의실**: 사물함, 거울, 벤치
- **바깥**: 노천탕, 폭포탕, 히노키탕, 탄산탕, 매점, 담장 너머 큰 폭포
- **지하 찜질방** (탈의실 오른쪽 계단): 불가마, 얼음방, 매트, 매점, TV

## 친구와 같이 들어가기

링크만 보내면 돼요. 같은 주소로 들어온 사람끼리 한 탕방에 모이고, 왼쪽 위에 **👥 지금 ○명**이 떠요.
친구가 안 보이면 학교·회사 와이파이 대신 휴대폰 데이터로 접속해 보세요.

### 동작 방식
- 서버 없이 브라우저끼리 직접 연결돼요(P2P). 처음 만날 때만 공개 Nostr 릴레이가 소개해 줘요.
- 탕방당 최대 12명이고, 꽉 차면 다음 방으로 자동 이동해요. 사람이 들어오면 가상 손님이 자리를 비켜줘요.
- 저장되는 데이터는 없어요. 지금 접속한 사람만 보여요.
- 방화벽이 강한 망에서는 일부 사람끼리 연결이 안 될 수 있어요(TURN 서버 없음).
- 테스트: 같은 브라우저의 탭끼리 시험하려면 주소 끝에 `?local`을 붙여요.
