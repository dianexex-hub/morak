# ♨ 가상온천 모락

함께 담그는 메타버스 온천

## 👉 [지금 들어가기](https://dianexex-hub.github.io/morak/)

설치도, 가입도 필요 없어요. 링크를 열면 바로 시작돼요. PC와 휴대폰 모두 돼요.

## 이용 방법

1. 위의 **지금 들어가기** 링크를 열어요.
2. 남색 천(溫泉) 아래 주황색 **들어가기** 버튼을 눌러요. 소리를 켜두면 더 좋아요.
3. 프런트 키오스크에서 닉네임과 모습을 꾸미고 체크인해요.
4. 1층 탈의실에서 시작해요. 사물함 앞에서 옷을 갈아입고, 정면 문으로 나가면 노천탕이에요.

| | PC | 휴대폰 |
|---|---|---|
| 걷기 | W A S D 또는 방향키 | 화면 왼쪽을 손가락으로 밀기 |
| 둘러보기 | 마우스를 누른 채 끌기 | 화면 오른쪽을 손가락으로 밀기 |
| 확대·축소 | 마우스 휠 | - |

- 탕 안으로 걸어 들어가면 자동으로 몸을 담가요.
- 화면 아래 버튼: **♨ 좋다~!** (외치기), **머리** (수건·양머리)
- 특정 장소에 가면 버튼이 더 생겨요: **갈아입기** (사물함), **매점** (팔찌 태그), **눕기** (찜질방 매트), **호출벨** (세신 코너), **키오스크** (프런트, 다시 꾸미기), **슬라이드 타기** (워터 슬라이드 사다리 앞)
- 왼쪽 아래 💬 채팅창은 접었다 펼 수 있어요
- 🍊 귤탕에서 **귤 까먹기**: 꼭지부터 껍질 까기 → 귤락 떼기 → 반 가르기 → 한 조각씩 먹기 (마우스·터치·키보드 ←→ / Space / Enter)

### 파일
- `index.html`: 온천 본체

### 수정·배포
- 저장소에서 `index.html`을 새 파일로 다시 올리면(Add file → Upload files) 1~2분 뒤 사이트에 반영돼요.
- 배포 설정: Settings → Pages → Deploy from a branch, `main` / `(root)`

### 버전 올리는 법
- `index.html` 맨 위의 `VERSION`, `BUILD_TIME` 두 값만 바꾸면 게임 안 표시가 모두 바뀌고, 접속 중인 사람에게 새 버전 알림이 떠요.
- 위 **업데이트 소식** 맨 위에 새 버전 칸을 추가해요 (최신이 위로).

### 동작 방식
- 서버 없이 브라우저끼리 직접 연결돼요(P2P). 처음 만날 때만 공개 Nostr 릴레이가 소개해 줘요.
- 탕방당 최대 12명이고, 꽉 차면 다음 방으로 자동 이동해요. 사람이 들어오면 가상 손님이 자리를 비켜줘요.

- 방화벽이 강한 망에서는 일부 사람끼리 연결이 안 될 수 있어요(TURN 서버 없음).
- 테스트: 같은 브라우저의 탭끼리 시험하려면 주소 끝에 `?local`을 붙여요.
