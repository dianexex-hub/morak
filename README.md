# ♨ 가상온천 모락

함께 담그는 메타버스 온천

## 👉 [지금 들어가기](https://dianexex-hub.github.io/morak/)

설치도, 가입도 필요 없어요. 링크를 열면 바로 시작돼요. PC와 휴대폰 모두 돼요.

## 이용 방법

1. 위의 **지금 들어가기** 링크를 열어요.
2. 남색 천(溫泉) 아래 주황색 **들어가기** 버튼을 눌러요. 소리를 켜두면 더 좋아요.
3. 1층 탈의실에서 시작해요. 사물함 앞에서 옷을 갈아입고, 정면 문으로 나가면 노천탕이에요.

| | PC | 휴대폰 |
|---|---|---|
| 걷기 | W A S D 또는 방향키 | 화면 왼쪽을 손가락으로 밀기 |
| 둘러보기 | 마우스를 누른 채 끌기 | 화면 오른쪽을 손가락으로 밀기 |
| 확대·축소 | 마우스 휠 | - |

- 탕 안으로 걸어 들어가면 자동으로 몸을 담가요.
- 화면 아래 버튼: **♨ 좋다~!** (외치기), **머리** (수건·양머리)
- 특정 장소에 가면 버튼이 더 생겨요: **갈아입기** (사물함), **매점** (팔찌 태그), **눕기** (찜질방 매트), **호출벨** (세신 코너)
- 왼쪽 아래 💬 채팅창은 접었다 펼 수 있어요
- 🍊 귤탕에서 **귤 까먹기**: 꼭지부터 껍질 까기 → 귤락 떼기 → 반 가르기 → 한 조각씩 먹기 (마우스·터치·키보드 ←→ / Space / Enter)
