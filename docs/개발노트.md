## 3. 기능 목록 (v2.11 기준)
**공통**
- 3인칭 시점: WASD/방향키, 마우스 드래그로 시점 회전, 휠로 줌. 휴대폰은 왼쪽 화면 밀기로 걷기, 오른쪽 밀기로 둘러보기.
- 하늘은 한국 시간 실시간 반영 (노을/밤/낮 전환 버튼), 눈 켜기/끄기, 소리 켜기/끄기.
- 버튼: ♨ 좋다~!(말풍선+합성 음성), 머리(없음/수건/양머리). 장소에 따라 갈아입기, 매점, 눕기, 호출벨, 귤 까먹기 버튼이 생김.
- 모든 문은 여닫이(안쪽으로 열림, 다가가면 열리고 멀어지면 닫힘). 문마다 비상구 표시. 626호만 잠겨 있음.
- 가짜 채팅창: 엔터를 누르면 "[속마음] 메시지"와 빨간 "온천 내에서는 조용히 해야합니다. (지배인 심)"이 뜸. 다른 사람에게는 전송 안 됨. 접기 가능.
- 버전 표시(화면 오른쪽 아래, 시작 화면, 도움말). 새 버전이 올라오면 접속 중인 사람에게 새로고침 배너가 뜸.

**1층 탈의실** (탈의실에서 시작)
- 마루 바닥, 사물함(갈아입기: 사복 → 수건 → 찜질복), 거울 세면대, 벤치, 신발장, 선풍기 2대.
- 세신 맛사지 가격표(어르신 오타와 드립 컨셉).
- 사물함 위로 올라가는 계단 → 2층 626호 "RxN Lab" 문(잠김). 다가가면 난처한 소리와 함께 ADHD 공지 → "문을 두들길까요?" → 똑똑똑 + "튼트리는 잘 있나요~?" 합성 음성과 자막 → "개발자가 아직 출근하지 않았습니다. 이제 막 옷을 입고 있다고 합니다".
- 오른쪽 계단으로 내려가면 지하 찜질방.

**바깥**
- 노천탕, 폭포탕, 히노키탕, 탄산탕, 🍊귤탕(이벤트탕). 탕마다 물대에서 물이 떨어짐. 탕에 들어가면 자동으로 몸을 담금.
- 담장 너머 큰 폭포, 은은한 돌바닥, 미끄럼 주의 팻말, 처마의 풍경(소리).
- 존나 용감한 노지감귤상: 청동색, 장군 포즈, 화강암 받침대에 금색 세로 글씨.
- 세신 코너(오른쪽 구석): 사무실 칸막이, 파란 세신대, 물통, 바가지, 수도꼭지, 호출벨(띵동, 20초 뒤 "사장님이 잠시 자리를 비운 듯 하다").
- 매점(왼편), 돌아다니는 손님 3명과 꼬마 3명. 위치를 공통 시계로 계산해서 모두에게 같은 자리에 보임.

**🍊 귤탕 (v2.1~2.11)**
- 귤 10개. "귤 까먹기"를 누르면 화면 아래 접시에 귤이 올라옴: 꼭지부터 껍질 까기 → 귤락 떼기(다 떼면 🏅 귤락 장인, 대충 넘기기 가능) → 반 가르기 → 한 조각씩 당겨 먹기. 키보드는 ←→ 고르기, Space 진행, Enter 먹기, Esc 내려놓기.
- 세 번째 귤부터 "배는 부른데 맛있다!" (음료 배부름과 별개).
- 귤 껍질 모으는 통(10개 = 꽉 참).
- 귤이 다 떨어지면 15초 뒤 🌾 농부 이상민이 말을 타고 등장 → 히이잉~(앞발 들기) → 바구니째 귤 투척 → 껍질 통 "뚝딱!" → 퇴장.
- 같은 탕방 사람들과 동기화: 귤 개수, 껍질 통, 농부 등장, 귤 위치, "🍊 귤 까는 중…" 표시. 같은 귤을 동시에 집으면 먼저 집은 사람이 가져감.

**지하 찜질방** (면적 약 48×24m)
- 방 6개: 불가마(황토 돔, 장작 소리), 박현빈 사랑방(들어가면 알림과 이글이글 화면), Alaska Pink Salt 방(빛나는 소금벽), 편백열방(통나무와 편백 큐브), 옥보석방(반짝이는 천연석), 습식사우나(들어가면 뿌얘짐).
- 사랑방 알림은 노래 가사를 쓸 수 없어서 새로 쓴 대사를 씀: "🔥 으아아 뜨거워라~! 가슴도 발바닥도 폐도 땀구멍도 눈물샘까지 활활 타오른다!"
- 매트(목침 쪽에 머리), TV(돌아가는 뉴스 자막), 매점.

**매점** (바깥과 찜질방)
- 마실 것: 커피우유, 바나나우유, 식혜, 녹차 / 먹을 것: 맥반석 계란 / 목욕용품 11종.
- 팔찌 "삑" 태그 모션 → 먹는 모션 (목욕용품은 "가방에 쏙"). 구매 기록은 브라우저 localStorage `morak-tab`에 쌓임 (나중에 계산 기능용).
- 1분 안에 음료 3잔이면 2분 동안 못 먹음: "배가 불러서 먹을 수 없다. 탈수기가 나를 돌려도 물이 한바가지는 나오겠다".

**온라인**
- 같은 주소로 들어온 사람끼리 "탕방"에 모임 (방당 최대 12명, 꽉 차면 다음 방). 사람이 들어오면 가상 손님이 하나씩 자리를 비켜줌.
- 위치·방향·자세·옷·머리·색·좋다~!·귤 까는 중 상태를 주고받음. 저장되는 데이터는 없음 (모두 나가면 초기화).
- `?local`을 붙이면 같은 브라우저의 탭끼리 시험 가능 (BroadcastChannel).

## 6. 작업·배포 방법
작업 규칙(브랜치, 버전, 배포 확인)은 `CLAUDE.md`를 따른다. 요약:
1. `main`을 pull해서 최신으로 맞추고 `feature/짧은설명` 브랜치를 딴다.
2. 브랜치에서 작업하고 push한다. 버전·README 업데이트 소식·노트 버전 항목은 건드리지 않고, 한 일은 10번 메모에 적는다.
3. 다이앤이 확인하면 `main`에 합친다. 이때 한 번만:
   - `index.html` 맨 위의 `VERSION`, `BUILD_TIME`을 다이앤이 정한 값으로 바꾼다.
   - README 「📢 업데이트 소식」 맨 위에 새 칸을 추가한다.
   - 이 노트의 버전 항목을 고치고 10번 메모를 본문에 반영한다.
4. 1~2분 뒤 사이트를 열어 버전 표시를 확인한다. GitHub API로 받은 파일의 SHA-256을 원본과 비교하면 확실하다.
- **올리는 수단:** claude.ai 채팅에서는 GitHub 커넥터로 Claude가 직접 커밋할 수 있다(2026-11-18 연결). 연결이 없으면 다이앤이 Add file → Upload files로 직접 올린다. Claude in Chrome은 파일 업로드가 막혀 있다.
- **테스트(Claude 쪽):** 작업 환경에서 headless Chrome(swiftshader)과 로컬 three.js로 화면을 찍어 확인. `?local`로 탭 두 개 동기화 시험. 실제 인터넷을 거친 P2P 연결은 작업 환경에서 시험할 수 없다.

- 제목 형식: `### v2.11 · 2026년 11월 18일 11:30 (KST)` (날짜와 시간 모두, 최신이 위로).
- 한마디 아래에 바뀐 점을 이모티콘 붙은 짧은 목록으로 쓴다.
- 버전 번호는 다이앤이 정한다 (지금까지 1.0 → 2.0 → 2.11). 버전 비교는 숫자 단위라 2.11 > 2.1 > 2.0.

  - v1.0: "🗓️ 2026년 11월 17일, ♨️ 첫 창업(?) 🤔 도전기 시작 ! 🚀✨"

## 9. 주의할 점
- 노래 가사·시는 쓰지 않는다 (사랑방 대사를 새로 쓴 이유).
- 수익화를 할 경우 실존 인물 이름("박현빈 사랑방" 등)은 퍼블리시티권 문제가 생길 수 있다.
- P2P라 한 방에 12명이 한계. 방화벽이 강한 망에서는 일부 연결이 안 될 수 있다 (TURN 서버 없음).
- 비즈니스 아이디어로 이야기한 것: 매점을 실제 후원으로, 이벤트탕 스폰서, 프라이빗 탕방 대관, 꾸미기 아이템, 목욕탕 B2B, 지원사업·연구. 아직 결정 안 함.

## 10. 브랜치 작업 메모
브랜치에서 한 일을 여기에 적는다. `main`에 합칠 때 위 본문(3~5번 등)에 반영하고 해당 메모는 지운다.

형식: `- feature/이름 (YYYY-MM-DD, 상태): 한 일 요약`

- feature/kiosk-checkin (2026-11-18, 다이앤 확인 대기): 입장 시 무인 키오스크 셀프 체크인.
