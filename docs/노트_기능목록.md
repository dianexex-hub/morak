# 모락 — 기능 목록 (개발노트 3번)

> `docs/개발노트.md`에서 나눈 상세 파일. 기능을 고칠 때 해당 부분만 grep해서 읽는다.

## 3. 기능 목록 (v4.0 기준)
**🖥️ 셀프 체크인 키오스크 (v2.3)**
- 들어가기 → 노렌이 열리면 무인 키오스크 화면: 1 닉네임 → 2 얼굴 → 3 상의 → 4 하의 → 5 모자 → 6 액세서리 → 7 확인 → 영수증 출력(사물함 번호, 입욕료 ₩0 "개발자가 아직 돈 받는 법을 몰라요") → 「♨ 입장하기」. 이때부터 이동과 온라인 접속이 시작됨.
- 위쪽 탭으로 단계 이동, 왼쪽 3D 미리보기(끌어서 돌리기), Enter=다음. 휴대폰은 미리보기가 위, 선택지가 아래.
- 닉네임: 최대 10자, 🎲 랜덤(형용사+목욕용품, 예: 노곤한 계란). 머리 위 이름표로 보이고 탕방에 공유.
- 얼굴: 피부색 12, 눈 8(웃는·동그란·반짝·졸린·윙크·감은·하트·놀란), 입 6(없음·미소·활짝·오~·고양이·메롱), 머리 모양 8(민머리·짧은·바가지·단발·포니테일·똥머리·양갈래·뽀글 파마), 머리색 10, 볼터치 있음/없음.
- 상의 10: 반팔 티·긴팔 티·나시·후드티·셔츠·줄무늬 티·니트 조끼·과잠·저고리·패딩.
- 하의 10: 긴바지·반바지·츄리닝·청바지·카고바지·몸빼바지·멜빵바지·미니스커트·롱스커트·수영복 트렁크.
- 모자 10+없음: 야구모자·비니·버킷햇·밀짚모자·베레모·중절모·왕관·고깔모자·고양이 귀·새싹 머리핀.
- 액세서리 10+없음: 동그란 안경·선글라스·목도리·목걸이·나비넥타이·귀걸이·백팩·천사 날개·이태리타올·오리 튜브.
- 색깔: 견본 16색 + 🎨 직접 고르기. 아이템을 바꾸면 그 아이템 기본색으로 바뀜.
- 저장: localStorage `morak-look`. 다음 방문 때 그대로이고, 첫 화면에 「지난번 모습 그대로 입장하기」가 뜸. 예전 `morak-color`는 피부색 기본값으로만 씀.
- 꾸민 옷은 "사복"에 적용됨. 수건·찜질복으로 갈아입어도 얼굴·머리·액세서리는 유지. 모자는 「머리」 버튼 첫 칸(내 모자)이고, 수건·양머리로 바꿔 쓸 수 있음.

**공통**
- 3인칭 시점: WASD/방향키, 마우스 드래그로 시점 회전, 휠로 줌. 휴대폰은 왼쪽 화면 밀기로 걷기, 오른쪽 밀기로 둘러보기.
- 하늘은 한국 시간 실시간 반영 (노을/밤/낮 전환 버튼), 눈 켜기/끄기, 소리 켜기/끄기.
- 버튼: ♨ 좋다~!(말풍선+합성 음성), 머리(내 모자/수건/양머리). 장소에 따라 키오스크, 갈아입기, 매점, 눕기, 호출벨, 귤 까먹기 버튼이 생김.
- 휴대폰(폭 600px 이하)에서는 장소 제목·설명이 왼쪽 위 버튼 아래로 가고 위쪽 버튼이 작아짐 (v2.3, 글씨 겹침 수정).
- 모든 문은 여닫이(안쪽으로 열림, 다가가면 열리고 멀어지면 닫힘). 문마다 비상구 표시. 626호만 잠겨 있음.
- 가짜 채팅창: 엔터를 누르면 "[속마음] 메시지"와 빨간 "온천 내에서는 조용히 해야합니다. (지배인 심)"이 뜸. 다른 사람에게는 전송 안 됨. 접기 가능.
- 버전 표시(화면 오른쪽 아래, 시작 화면, 도움말). 새 버전이 올라오면 접속 중인 사람에게 새로고침 배너가 뜸.

**🏛️ 건물 Sauna Morak (v4.0)** — 땅 위 48×48m(x -24~24, z 28~76), 앞쪽 절반은 지하 찜질방 바로 위. 바깥에서 보면 화강암 2층 건물 위로 23층 타워 3동(곡선 앞면) + 옥상 스카이파크(마리나 베이 샌즈 느낌).
- **정면**: 「SAUNA MORAK · 사우나 모락 24시」 간판, 입구 차양과 풍경, 溫泉 노렌. 정문(가운데)은 로비로, 양옆 앞문(男 남탕·女 여탕 노렌)은 각 탈의실로 바로 들어감.
- **1층 로비**(x -12~12, z 28~52, 앞쪽 z<40은 2층까지 뚫림): 시작 위치. 입구 바로 양옆 대계단(레드카펫, 금색 난간)으로 2층, 샹들리에 2개. 왼쪽(서쪽) 프런트 카운터(사진처럼 화강암 + 검은 상판, 뒤쪽 대리석 벽 「사우나 모락 24시 · Sauna Morak」, 수건 선반)에 정장 차림 🤵 지배인 심(가끔 말풍선). 지배인의 왼쪽 앞 작은 데스크에 무인 키오스크. 체크인·다시 꾸미기는 「🖥 키오스크」 또는 「🤵 지배인 심에게 체크인」(같은 화면인데 머리글이 「지배인 심 · 직접 도와드릴게요」, 영수증에 「담당 지배인 심」). 오른쪽에 지하로 내려가는 계단(예전 자리), 신발장, 안쪽 가운데 엘리베이터(0,44), 소파·화분, 뒷벽 문 두 개로 모락 식당.
- **남탕·여탕 탈의실**(서쪽 x -24~-12 / 동쪽 12~24, z 28~52): 로비 쪽 입구(z 42~43.6), 앞문은 노천탕으로, 뒷문은 실내 목욕탕으로. 바깥벽 사물함 + 가운데 세운 회색 사물함 두 줄(사진처럼), 벤치, 거울 세면대, 선풍기, 세신 맛사지 가격표(뒷벽). 사물함 근처에서 「👕 갈아입기」(사복 → 수건 → 찜질복).
- **실내 목욕탕**(z 52~76): 온탕 40℃, 열탕 43℃, 냉탕 18℃(냉온탕 챌린지에도 쓰임), 샤워 자리 6개, 건식 사우나(90℃).
- **모락 식당**(가운데 뒤쪽): 테이블 6개, 카운터, 메뉴판(라면·김밥·계란·식혜). 주문은 아직 안 됨.
- **2층**(바닥 높이 4): 로비 위 갤러리(대리석 난간) + 살롱(소파, 엘리베이터), 서쪽 수면실(매트 8개 · 🛏 눕기, 문 있음)과 626호 "RxN Lab"(잠김. 다가가면 난처한 소리와 ADHD 공지 → "문을 두들길까요?" → 똑똑똑 + "튼트리는 잘 있나요~?" → "개발자가 아직 출근하지 않았습니다…"), 동쪽 안마의자 라운지(「💺 안마 받기」 8초, 화면이 살짝 떨림)와 만화방(책장·빈백).
- 건물 안 표지판은 벽에 붙이거나 천장에 줄로 매담(`hangRods`).

**바깥**
- 노천탕, 폭포탕, 히노키탕, 탄산탕, 🍊귤탕(이벤트탕). 탕마다 물대에서 물이 떨어짐. 탕에 들어가면 자동으로 몸을 담금.
- 담장 너머 큰 폭포, 은은한 돌바닥, 미끄럼 주의 팻말, 처마의 풍경(소리).
- 존나 용감한 노지감귤상: 청동색, 장군 포즈, 화강암 받침대에 금색 세로 글씨.
- 세신 코너(오른쪽 구석): 사무실 칸막이, 파란 세신대, 물통, 바가지, 수도꼭지, 호출벨(띵동, 20초 뒤 "사장님이 잠시 자리를 비운 듯 하다").
- 매점(왼편), 돌아다니는 손님 3명과 꼬마 3명. 위치를 공통 시계로 계산해서 모두에게 같은 자리에 보임.

**🍊 귤탕 (v2.1~2.11)**
- 귤 10개. "귤 까먹기"를 누르면 화면 아래 접시에 귤이 올라옴: 꼭지부터 껍질 까기 → 귤락 떼기(다 떼면 🏅 귤락 장인, 대충 넘기기 가능) → 반 가르기 → 한 조각씩 당겨 먹기. 키보드는 ←→ 고르기, Space 진행, Enter 먹기, Esc 내려놓기.
- 세 번째 귤부터 "배는 부른데 맛있다!" (음료 배부름과 별개).
- 귤 껍질 모으는 통(10개 = 꽉 참).
- 귤이 다 떨어지면 15초 뒤 🌾 농부(화면 표시 이름. v4.0.1부터 「이상민」을 잠시 뺌)가 말을 타고 등장 → 히이잉~(앞발 들기) → 바구니째 귤 투척 → 껍질 통 "뚝딱!" → 퇴장.
- 같은 탕방 사람들과 동기화: 귤 개수, 껍질 통, 농부 등장, 귤 위치, "🍊 귤 까는 중…" 표시. 같은 귤을 동시에 집으면 먼저 집은 사람이 가져감.

**🐴 농부 순찰 (v2.3.1)** — v4.0.1부터 화면에는 「농부」로만 표시 (이름표·안내·도움말. 코드 이름 `farmer`·`ROAM`은 그대로)
- 10분마다 3분(플레이 시간의 30%) 말을 타고 바깥을 돈다. 공통 시계(`Date.now()`)로 계산해서 모두에게 같은 시간·같은 자리에 보임 (`ROAM.cycle=600`, `win=180`, `off=137`).
- 귤 배달과 같은 동쪽 입구(40, -20.6)로 들어와 노천탕 주변을 크게 5바퀴 돌고 같은 길로 나감. 탕·석등·정자 기둥과 최소 1m 떨어진 길(`R_IN`, `R_LOOP`), 약 2.8m/s. 말발굽 소리, 24초마다 말풍선("다들 잘 담그고 계시죠~?", "순찰 중입니다~", "히이잉~" 등).
- 귤 배달(`FARM.active`)이 우선. 순찰 중 배달이 시작되면 그 자리에서 반짝 사라졌다가 배달 동선으로 나타나고, 배달이 끝난 뒤 순찰 시간이 남았으면 순찰 자리에 반짝 다시 나타남.

**지하 찜질방** (면적 약 48×24m)
- 방 6개: 불가마(황토 돔, 장작 소리), 박현빈 사랑방(들어가면 알림과 이글이글 화면), Alaska Pink Salt 방(빛나는 소금벽), 편백열방(통나무와 편백 큐브), 옥보석방(반짝이는 천연석), 습식사우나(들어가면 뿌얘짐).
- 사랑방 알림은 노래 가사를 쓸 수 없어서 새로 쓴 대사를 씀: "🔥 으아아 뜨거워라~! 가슴도 발바닥도 폐도 땀구멍도 눈물샘까지 활활 타오른다!"
- 매트(목침 쪽에 머리), TV(돌아가는 뉴스 자막), 매점.

**매점** (바깥과 찜질방)
- 마실 것: 커피우유, 바나나우유, 식혜, 녹차 / 먹을 것: 맥반석 계란 / 목욕용품 11종.
- 팔찌 "삑" 태그 모션 → 먹는 모션 (목욕용품은 "가방에 쏙"). 구매 기록은 브라우저 localStorage `morak-tab`에 쌓임 (나중에 계산 기능용).
- 1분 안에 음료 3잔이면 2분 동안 못 먹음: "배가 불러서 먹을 수 없다. 탈수기가 나를 돌려도 물이 한바가지는 나오겠다".

**🛝 새 탕 4개 · 이레즈미 손님 (v2.4)**
- 🛝 슬라이드탕(26,4, 34℃): 동쪽에 파란 탑(사다리) + 노란 반원 미끄럼 + 물줄기. 사다리 앞(29.75, 9.5)에서 「🛝 슬라이드 타기」 → 사다리 오르기 → 약 3.9초 미끄러져 풍덩. 타는 동안 조작 잠금(`SLIDE.ride`, `slideRide`). 위치(높이 포함)를 그대로 보내서 다른 손님도 내가 타는 모습을 봄. 꼬마 하나가 공통 시계로 26초마다 타고 내려옴(`kidFrame`, 「꺄아~」 → 「풍덩!」).
- 🍌 바나나우유탕(-28.6,-7, 38℃): 기울어진 큰 우유병이 쏟아붓고 큰 줄무늬 빨대가 꽂혀 있음. 들어가면 「바나나우유에 퐁당!」.
- 🌿 쑥탕(-20,-29, 41℃, 5×4 사각 돌탕): 약재 주머니 3개가 둥둥, 쑥 다발. 들어가면 「쑥 향이 코끝을 찌른다…」.
- 🧊 얼음 냉탕(16,19.5, 16℃): 얼음 조각 12개(인스턴싱, 둥둥), 목도리 펭귄상, 김 없음. 들어가면 파란 테두리(`#coldOv`) + 「으아아아 차가워!!」 + 덜덜 소리, 30초 지나면 「국룰대로 온탕으로 ♨」.
- 새 탕은 `pools` 배열 뒤에 덧붙여서 담그기·HUD·물소리가 기존 탕과 똑같이 동작. 탕마다 팻말(`nbSign`).
- 🐉 「🌸 꽃집 형님」: 등에 용·가슴 양쪽 모란·팔에 잉어 문신(캔버스 텍스처, `inkUp`), 냉탕 둘레 산책. 처음 가까이 가면 「😳 …등에 용이?!」, 그 뒤 3.4m 안에 들어가면 말풍선(「딸이 고른 도안이에요」 등). 쑥탕에는 잉어 문신 할아버지가 앉아 있음.
- 손님 더: 탕에 담근 손님 9명(새 탕 + 노천탕), 걷는 손님 3명(꽃집 형님, 서쪽 수건 손님, 남쪽 찜질복 손님) + 슬라이드 꼬마.
- 성능: 새 탕이 보이는 곳에서 그리기 횟수가 약 20~30% 늘어남(주로 사람 아바타). 꼬마 몸통도 합침.

**🛗 엘리베이터 (v3.0, v4.0에서 자리 정리)**
- 지하·1층·2층 모두 같은 자리(0,44), 문은 남쪽(로비 쪽)을 봄. 옥상은 같은 자리에서 북쪽(탕 쪽)으로 나옴. 층마다 문짝 2장(가운데서 열림)·실내 칸(거울·손잡이·버튼판·층 표시)·복도 쪽 층 표시·호출 버튼이 따로 있음(`EFL`, `buildCab`). 면이 겹쳐 깜박이던 실내 판은 조금씩 안쪽으로 띄움(v4.0).
- 문 앞에서 「🛗 엘리베이터」 → 띵 + 「문이 열립니다」 → 자동으로 타고 → 층 선택(R·2·1·B1) → 「문이 닫힙니다」 → 층수가 B1·1·2·3…22·R로 바뀜(처음·끝 0.85초, 중간 층마다 0.27초) → 도착 층 칸으로 옮겨짐 → 「○층입니다」 → 문 열림 → 자동으로 내림. 지하~2층 안내는 한국어, 옥상은 불어(« Les portes s’ouvrent / se ferment »). 안내는 자막 + 합성 음성.
- 타는 동안 조작 잠금(`lockMove`). 실내는 문이 열렸거나 타고 있을 때만 그림.

**🇫🇷 23층 옥상 Toit-terrasse (v3.0)**

**⚡ 성능 (v2.3.1)**
- 움직이지 않는 메시를 재질별로 합쳐 그리기 횟수를 절반 넘게 줄임 (탈의실 737→349, 바깥 479→182, 찜질방 927→423). scene 바로 아래의 불투명 Lambert/Basic 메시는 재질 모양과 40m 구역별로, 가만히 있는 손님 아바타는 통째로, 걷는 NPC는 팔다리를 빼고 몸통만 합침 (`mergeStatic`, `mergeUnder`). 합친 원본은 장면에서만 빠지고 카메라 충돌(`blockers`)에는 그대로 쓰임. 시간대에 따라 색이 바뀌는 `lampMat`은 따로 묶음.
- **⚠️ 앞으로 움직일 물건을 scene에 바로 넣을 때는 `mesh.userData.dyn=1`을 붙여야 합쳐지지 않는다.** (그룹 안에 넣은 물건은 해당 없음. 단, 손님 아바타와 걷는 NPC 몸통은 합쳐지므로 나중에 바꾸려면 합치기 대상에서 빼야 함.)
- 김(수증기) 약 150개를 인스턴싱 메시 하나로 그림 (`SB`, `sbBuild`/`sbUpdate`). `mkSprite()`는 위치·크기·투명도만 담은 대리 객체를 돌려줌.
- 해상도 자동 조절: 휴대폰은 최대 ×1.5로 시작, 2초 평균 38fps 아래면 0.2씩 낮춤(최저 ×0.8, PC는 ×1), 57fps 이상이면 다시 올림.
- 주소 끝에 `?fps` → 화면 위에 fps·그리기 횟수·삼각형·해상도·합친 개수 표시.
- 화면 가장자리 비네트(`#vign`).
- 남은 큰 부담: 걷는 NPC와 다른 손님 아바타(사람당 10~20번), 간판처럼 텍스처가 제각각인 물체.
